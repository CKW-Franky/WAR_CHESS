# WAR CHESS｜大規模兵團戰棋

**版本 1.0** ｜ 中國古代背景的回合制戰棋
每個單位是一支數百人的兵團；傷亡以「兵力」遞減呈現，而不是單純扣血條。

## 1.0 內容

- **只有快速模式**：主選單 → 選 5 個單位 → 部署 → 單場戰鬥。
- **六個正規兵種**，每個兵種一套固定裝備。
- **技能綁在武器上**，角色 class 本身沒有主動技能。
- **簡化士氣**：100 有傷害加成、50 中性、50 以下受傷增加。
- **橋樑、河流、森林、高地、山地**與接戰容量。
- 無遠征、將領、武廟、靈魂祭壇、存檔槽。

## 快速開始

### 需求

- Windows
- Python **3.10+**（實測 3.13.7）
- pygame **2.6+**（實測 2.6.1）

### 安裝與執行

```powershell
cd Battle_Chess_v1.0
py -3 -m pip install -r requirements.txt
py -3 main.py
```

或直接雙擊 `run_game.bat`。

> 遊戲沒有外部圖片、音效或字型檔；使用 Windows 系統字型。

## 操作

| 操作 | 功能 |
|---|---|
| **左鍵** | 選擇單位、移動、攻擊、確認技能目標 |
| **右鍵／Z** | 撤銷尚未確定的移動 |
| **方向鍵** | 選擇單位面向（影響被攻擊角度） |
| **E／技能按鈕** | 施放**目前武器**的技能；懸停顯示說明與 AP |
| **C** | 騎兵衝鋒開關 |
| **T／遠射** | 長弓額外技能：25 AP，本回合射程 +1 |
| **R／裝填** | 弩兵專用：50 AP，裝填當回合不能再射 |
| **F** | 弓類武器切換穿甲箭／火矢 |
| **Q／追擊** | 站樁時 40 AP，打出 60% 傷害；弩不適用 |
| **Space** | 結束回合 |
| **ESC** | 取消技能目標／操作 |
| **分裂／合併** | 兵團分裂或合併 |
| **地格懸停** | 顯示地形效果、移動消耗與接戰容量 |

## 技能

技能全部由武器提供；`units/*.py` 不再定義 `skill_name` 或 `execute_skill`。

| 武器 | 主要技能 | 額外技能 |
|---|---|---|
| 刀 | 援護架盾（40 AP） | — |
| 長槍 | 拒馬槍陣（25 AP） | — |
| 騎槍 | 破陣衝撞（60 AP） | — |
| 短弓 | 神速連射（40 AP） | F：火矢切換（10 AP） |
| 長弓 | 換矢（10 AP） | 遠射（25 AP） |
| 弩 | 精密校準（40 AP） | 裝填（50 AP） |

- 技能按鈕讀 `weapon.skill_id`。
- 額外技能讀 `weapon.extra_skill_id`。
- 盾牌與甲的被動效果仍然存在，但不是角色主動技能。

## 戰鬥規則

- **兵力制血量**：`總 HP = 兵力 × 每兵 HP`；傷害先扣 HP，扣滿一個兵的份額就減 1 兵力。
- **接戰人數**：近戰 `min(兵力, 攻方地形容量, 守方地形容量)`；遠程上限 **150**。
- **攻擊角度**：正面／側面／背面；側背有傷害加成。
- **命中**：受地形、目標狀態與武器影響，夾在 15%～95%。
- **反擊**：近戰被攻擊時反擊；長槍兵對騎兵反擊 ×3。
- **士氣**：
  - 100：造成傷害 **+20%**
  - 50：無加成
  - 50 以下：受到傷害增加，0 時 **+50%**
  - 只會被傷害降低，不會潰散
- **騎兵衝鋒**：累積動能；衝鋒造成貫穿。
- **弓箭手**：換矢切換穿甲箭／火矢；遠射另外花 25 AP。
- **弩兵**：站樁射擊會自動裝填；移動後需花 50 AP 裝填，裝填當回合不能再射。
- **追擊**：未移動時 40 AP，60% 傷害；弩不適用。
- **傷害預覽**：顯示接戰人數、盾牌格擋、森林、移動後射擊與距離衰減。
- **AI**：會評估地形、分裂、遠程風箏與衝鋒。

## 地形

地圖 **16 × 20** 格（`GRID_SIZE = 48`，畫面 1088×960）。
河流固定橫貫 y=9、10；橋樑固定在 **x=3、8、12**。

| 地形 | 額外移動 | 可通行 | 接戰容量 | 效果 |
|---|---|---|---|---|
| 平原 | 0 | 全部 | 220 | — |
| 森林 | 0 | 全部 | 70 | 守方在森林：遠程傷害減半 |
| 高地 | +1 | 全部 | 180 | 守方防禦 ×1.1 |
| 河流 | 步兵 +2／騎兵 +1 | 全部 | 120 | — |
| 橋樑 | 0 | 全部 | 220 | 跨河不減速 |
| 山地 | +2 | 僅步兵 | 50 | 遠程站上去射程 +1、命中 +15 |

基礎移動：正交 1、斜向 2，再加地形額外值（最低 1）。
