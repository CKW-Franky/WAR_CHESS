# 戰棋（WAR CHESS）

一款以中國古代為背景的**回合制戰棋遊戲**，主打「大規模兵團」作戰：每個單位是一支有數百名士兵的部隊，傷亡以「兵力」遞減呈現，而非單純的血條。

## 快速開始

### 環境需求

- Python **3.10+**（開發環境為 3.13）
- pygame **2.6+**

### 安裝與執行

```bash
# 1. 進入專案資料夾
cd Battle_Chess

# 2. 安裝相依套件
pip install -r requirements.txt

# 3. 啟動遊戲
python main.py
```

> 相依套件只有 `pygame`（見 `requirements.txt`）。

## 操作說明

| 操作 | 說明 |
|---|---|
| **左鍵點擊** | 選擇單位 / 確認移動或攻擊目標 |
| **移動** | 點擊藍色可移動格；移動後可再攻擊 |
| **攻擊** | 點擊射程內的敵方單位 |
| **結束回合** | 點擊「結束回合」按鈕 |
| **右鍵 / 撤銷** | 撤銷尚未確定的移動 |

| **投石機按鈕** | 攻城戰中站在投石機上時出現 |

## 兵種

六個正規兵種各有明確定位，採「兵力 × 每兵 HP」的血量模型（`hp` = 總兵力池）。

| 單位 | 定位 | 兵力 | 攻擊 | 防禦 | 射程 | 速度 | MP | 技能 | 特性 |
|---|---|---|---|---|---|---|---|---|---|
| **槍騎兵** | 破陣突擊 | 200 | 2400 | 200 | 1 | 120 | 6 | 破陣衝撞 (60) | 騎兵；衝鋒貫穿、無視部分防禦、不可反擊 |
| **弓騎兵** | 騷擾風箏 | 200 | 2000 | 150 | 5 | 130 | 7 | 神速連射 (40) | 騎兵；移動後射擊折扣、被貼身可撤退 |
| **長槍兵** | 反騎主力 | 400 | 1150 | 400 | 1 | 95 | 4 | 拒馬槍陣 (25) | 步兵；對騎兵反擊 ×3、拒馬 |
| **盾兵** | 坦克 | 500 | 900 | 450 | 1 | 90 | 4 | 援護架盾 (40) | 步兵；盾牆援護，每回合限一次 |
| **弓箭手** | 遠程主力 | 400 | 2900 | 100 | 5 | 100 | 4 | 換矢 (30) | 弓兵；切換破甲／火箭／遠射（一次性） |
| **弩手** | 破甲火力 | 400 | 3000 | 0 | 5 | 80 | 4 | 精密校準 (40) | 弓兵；校準期間無視防禦，且無法被反擊 |

**雜兵（遠征前期敵人）**：流寇、馬匪、林中強盜、逃兵、山賊。

### 進化路線（3★ 二選一）

每個兵種在 3★ 時可從 A / B 兩條路線擇一，影響專屬機制（例如槍騎兵「破軍鐵騎」動能上限 +3、「鐵壁重騎」衝鋒時遠程減傷 40%）。

## 戰鬥系統

- **兵力制血量**：`總 HP = 兵力 × 每兵 HP`。傷害先扣總 HP，扣完一個「兵」的份額就減 1 兵力；傷害會隨兵力衰減（防禦與攻擊都有 floor）。
- **整數移動力**：正交移動消耗 1，斜向消耗 2；地形再疊加修正，最低 1。
- **攻擊角度**：正面 / 側面（FLANK）/ 背面（REAR）。背面加暴擊率，盾兵進化可免疫背面加傷。
- **命中率**：基礎命中受士氣、地形、目標狀態、將領韜略影響，夾在 15%～95%。
- **暴擊**：基礎 5%，背面 +15%、士氣 ≥ 80 +10%、將領加成。暴擊傷害 ×1.5。
- **通用反擊**：近戰被攻擊時會反擊（`DEFENSE_K` 公式），但背面攻擊、士氣 ≤ 30、AP 不足、或攻擊方有「無反擊」狀態時不反擊。長槍兵對騎兵反擊 ×3。
- **士氣**：非線性變化（`傷害比例 × 40 + 擊殺比例 × 60`），士氣歸零潰散。
- **騎兵衝鋒**：累積動能，衝鋒造成貫穿（必中、無視部分防禦、不可反擊）。分裂兄弟潰散時額外打擊士氣。
- **弓箭手箭矢**：換矢後的那一擊為一次性，攻擊後消耗（預覽不消耗）。
- **AI**：會評估地形偏好（高地給遠程、村莊給殘兵）、規劃分裂、風箏（弓騎兵偏好 2～3 格距離）。

## 地形系統

地圖為 **16 × 20** 格（`GRID_SIZE = 48`，畫面 1088×960）。

| 地形 | 移動 | 戰鬥效果 |
|---|---|---|
| 平原 NORMAL | 1 | — |
| 森林 FOREST | 1 | 守方在森林：遠程傷害 **減半**、被命中率 -20（遠程）/-10（近戰）；阻擋視線 |
| 山地 MOUNTAIN | 不可通行 | 遠程站上去：射程 **+1**、命中 **+15** |
| 河流 RIVER | 步兵 +2 / 騎兵 +1 | 站在河上被命中 **+20** |
| 道路 ROAD | **-1**（最低 1） | — |
| 沼澤 SWAMP | +1 | 守方防禦 **×0.8** |
| 高地 HIGHLAND | +1 | 守方防禦 **×1.1**；遠程站上去射程 +1、命中 +15 |
| 村莊 VILLAGE | +1 | 守方防禦 **×1.2**；每回合補兵 **5%** |
| 廢墟 RUINS | +1 | 遠程傷害 **×0.7**（掩體） |
| 柵欄 FENCE | 不可通行 | 可破壞，HP 100 |
| 橋樑 BRIDGE | 1 | — |
| **城牆 WALL** | 不可通行 | 攻城戰結構 |
| **城門 GATE** | 不可通行 | 攻城戰結構，可破壞 **HP 500** |
| **兵營 BARRACKS** | 1 | 每回合補兵 **5%** |
| **民房 HOUSE** | 不可通行 | 攻城戰結構 |
| **投石機 CATAPULT** | 1 | 可互動：投石破門（攻城戰） |

> 地圖生成保證：河流為整列連續、橋樑 1～2 座且與道路對齊、柵欄避開雙方起始區。

### 攻城戰地圖（遠征模式）

攻城關卡使用專屬模板：敵方半場有**城牆 + 城門 + 兵營 + 民房**，我方半場有**投石機**，地形以道路／平原／森林／高山為主。

- 敵方遠程單位獲得**城牆加成**（射程 +1、命中 +15）。
- 城門是唯一缺口，血量厚（500），可用投石機（一次 300 傷害）或近戰破壞。
- 投石機：站在上面的我方單位可投石，**專門破門**。

## 兵團分裂與合併

- **分裂**：兵力 ≥ 200 且 AP ≥ 30 時，可把兵團一分為二，各佔一半兵力。分裂出的單位是**臨時單位**（戰後併回原小隊，不額外佔人口）。
- **合併**：相鄰、同名、同隊且兵力總和不超過上限時可合併。
- **小隊（Squad）**：分裂出的單位仍屬於原小隊，**繼續受到隊長的加成**。

## 隊長系統

隊長（將領）有五維屬性，**上限 100**，招募時隨機生成。

| 屬性 | 效果 |
|---|---|
| **武勇**（wu） | 傷害 +0.5% / 點 |
| **韜略**（mou） | 命中 +0.3 / 點，並增加暴擊 |
| **統御**（tong） | **兵力上限 +2 / 點**、防禦 +1 / 點 |
| **智略**（zhi） | 戰後兵力回收（每場回復損失兵力） |
| **氣運**（yun） | 暴擊率、局外收益 |

- 部署時可把隊長**指定給一支小隊**（錨點單位）。
- 指派會**跨關卡記住**：下一場自動沿用同一支小隊，不需重新指派。
- 隊長陣亡／退役時，其指派自動清除。

## 局外成長（靈魂祭壇）

- **靈魂點數**：跨存檔累積，用於點亮技能樹（攻擊、防禦、經濟等分支）。
- **武廟**：將領的生命週期管理——正殿 → 丁憂 → 配享／英烈。配享會轉化為**永久兵種增益**（騎兵衝鋒、步兵防禦、弓兵命中）。
- **統計與成就**：最高星級、攻城勝場、局外收益等。
- META 資料會在**程式結束時自動保存**。

## 更新內容

### 最新：遠征模式重構 + 穩定化

**遠征模式（測試版）**
- 開局改為**選擇 3 個兵種 + 招募 1 位隊長**。
- 部署時可**為隊長指定一支小隊**；小隊分裂後仍受隊長指引。
- 隊長五維重新定義（武勇→傷害、韜略→命中/暴擊、統御→+2 兵/防禦、智略→戰後回收、氣運→暴擊/局外收益）。
- 遠征地圖改為**殺戮尖塔式三節點選路**：每層 10 欄 × 3 節點，**第 5、10 關為攻城戰**；節點含遭遇戰／商店／營地／未知（事件）。
- 暫做**兩層**：第 1 層第 5 關＝佔領小鎮（2 正規軍）、第 10 關＝佔領堡壘（3）；第 2 層第 5 關＝佔領城堡（4）、第 10 關＝佔領城鎮（5）。
- 新增**攻城戰地圖模板**：城牆、城門（厚血）、兵營（補血）、民房（阻擋）、投石機（破門）與攻城專屬地形。
- 攻城獎勵、普通獎勵、武廟沿用既有設定。

**遠征模式 bug 修復**
- 修復「分裂＝憑空損失一半兵力」：分裂單位戰後**併回原小隊**，兵力不再消失。
- 修復「部隊莫名從 3 個變 2 個、最後剩 1 個」：原單位戰死但分裂單位存活時，小隊不再整支消失。
- 修復「上一關兵力沒繼承」：roster 以穩定 `uid` 為鍵，單位死亡造成的索引位移不會對錯小隊。
- 攻城獎勵不再與「永久人口」獎勵重複疊加。
- 傷害預覽改為取暴擊期望值（不再因隨機暴擊而跳動）。
- AI 分裂後不再浪費 AP 施放技能。

### 戰鬥與平衡

- **11 項戰鬥機制重構**：整數移動力、百分比防禦、非線性士氣、通用反擊、近戰命中 < 100%、暴擊、遠程被近戰、ZOC 僅在離開時觸發、六兵種數值、兵種專屬機制、進化路線。
- **六兵種重新設計**，定位分明：槍騎兵＝破陣、弓騎兵＝騷擾、長槍兵＝反騎、盾兵＝坦克但不肉、弓箭手＝遠程主力、弩手＝破甲高火力。兩個騎兵略強以符合機動定位。
- 新增 `simulate_balance.py` 對戰模擬器與 `test_balance.py` 數值驗證。

### 地圖與地形

- 地圖擴大為 **16×20**（1088×960）。
- 新增地形：河流、橋樑、沼澤、高地、村莊、廢墟、柵欄，並加入對應戰鬥效果與繪製圖示。
- AI 加入地形偏好（高地給遠程、村莊給殘兵、避開沼澤）。

### 兵團機制

- 新增**兵團分裂與合併**（含分裂高亮、AI 分裂決策）。
- 分裂／合併與人口、roster、隊長小隊的連動。

### 將領與局外

- 武廟系統（正殿／丁憂／配享／英烈）、將領戰功與官職。
- 靈魂祭壇技能樹、跨週目昇華。
- 存檔位置改為專案內 `save_data/`；META 退出時自動保存。

### 快速模式

- 快速模式固定 **5 名敵軍**。
- 戰鬥結束後可選擇**再來一局**或**退出到主介面**。

### 其他修復

- 修復：將領初始面向顛倒、`_eval_angle` 前後方判定錯誤、擊殺數顯示為 0、反擊使用扣血後的攻擊力、快速模式人口閘門、`add_exp_all` 迭代空字典、`from town import UNLOCK_ORDER` 匯入錯誤等。

## 存檔位置

所有存檔位於專案資料夾內的 **`save_data/`**：

```
save_data/
├── slot_1/ … slot_N/    # 各存檔槽
├── meta.json            # 局外成長（靈魂點、技能樹、統計）
└── temple.json          # 武廟（將領）
```

備份或轉移進度時，複製整個 `save_data/` 即可。
